getNames: ใช้ .map() เพื่อดึงเฉพาะฟิลด์ name จาก Array ของนักศึกษาทุกคนออกมาสร้างเป็น Array ของ String ใหม่

getPassedStudents: ใช้ .filter() คัดเลือกเอาเฉพาะวัตถุ (Object) นักศึกษาที่มีคะแนน (score) ตั้งแต่ 50 ขึ้นไป

getTotalScore: ใช้ .reduce() เพื่อบวกรวมคะแนนทั้งหมด โดยกำหนดค่าเริ่มต้น accumulator ให้เป็น 0

getAverageScore: นำคะแนนรวมจาก getTotalScore มาหารด้วยจำนวนนักศึกษา (length) และเช็คเงื่อนไขถ้า Array ว่าง ให้ คืนค่า 0 ทันทีเพื่อป้องกันปัญหาการหารด้วย 0 ซึ่งจะส่งผลให้ได้ค่า NaN (Not a Number) พร้อมตัดทศนิยมด้วย .toFixed(2)

countByGrade: ใช้ .reduce() โดยมีค่าเริ่มต้นเป็น Object 空 ({}) วนลูปนำคะแนนของนักศึกษาแต่ละคนไปคำนวณเกรด แล้วนำเกรดนั้นไปเพิ่มนับจำนวนสะสมไว้ใน Object (เช่น { A: 2, B: 1 })

getTopStudent: ใช้ .reduce() เปรียบเทียบหาคนที่มีคะแนนสูงสุด โดยเปรียบเทียบนักศึกษาคนปัจจุบันกับคนที่คะแนนสูงที่สุดที่บันทึกไว้ และมีระบบเช็คถ้าเป็น Array ว่างจะ คืนค่า undefined
